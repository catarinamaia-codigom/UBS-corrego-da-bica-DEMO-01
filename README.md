# BICA — Demonstração de Pesquisa Territorial v0.5

Esta pasta contém uma versão **estática**, com entrevistas e coordenadas **fictícias**, pronta para GitHub Pages.

## Publicar
1. Crie um repositório público no GitHub (por exemplo, `bica-pesquisa-territorial-demo`).
2. Entre nele, use **Add file → Upload files**, e envie `index.html` e `.nojekyll` desta pasta (você também pode enviar este `README.md`).
3. Em **Settings → Pages**, selecione **Deploy from a branch**, `main`, `/(root)` e salve.
4. Acesse a URL exibida pelo GitHub Pages. Geralmente tem o formato `https://SEU-USUARIO.github.io/bica-pesquisa-territorial-demo/`.

> **ATENÇÃO:** O GitHub Pages é público, inclusive o HTML e o JavaScript publicados. Não inclua planilhas reais, nomes de moradores, documentos, tokens ou senhas. Esta demonstração não salva dados no servidor.

## O que a versão oferece
Visão geral com mapa e polígonos ilustrativos, indicadores, oito entrevistas fictícias, ficha individual, cadastro de ruas, construtor e governança de termos/PDF. A troca de papéis na tela é visual, não autenticação.

## Google Maps
A opção de mapa híbrido do Google requer uma chave da Maps JavaScript API configurada e restrita ao domínio publicado; há custos e limites potenciais. A demonstração pode usar mapas alternativos. Coordenadas fictícias não viram posições reais quando você ativa o mapa.
